💅 Ana Rosa Nail Designer

Landing Page desenvolvida para Ana Rosa Nail Designer, com foco em apresentar os serviços de forma elegante, profissional e estratégica, facilitando o contato e o agendamento de clientes.

✨ Sobre o projeto

O projeto foi desenvolvido com uma proposta moderna, sofisticada e responsiva, valorizando a identidade visual da profissional e criando uma experiência agradável para visitantes em dispositivos desktop e mobile.

A página apresenta os principais serviços, diferenciais e informações da profissional, além de chamadas estratégicas para incentivar o contato e o agendamento.

🎯 Objetivos
Apresentar a profissional de forma profissional
Destacar os serviços oferecidos
Valorizar o trabalho e a identidade da marca
Facilitar o contato com potenciais clientes
Criar uma experiência moderna e intuitiva
Adaptar a experiência para smartphones, tablets e desktops
🖥️ Tecnologias utilizadas
HTML5 — Estrutura semântica da página
CSS3 — Estilização, responsividade e identidade visual
JavaScript — Interações e funcionalidades
Google Fonts — Tipografia
Responsividade — Layout adaptado para diferentes dispositivos
